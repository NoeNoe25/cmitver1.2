# SIITEC Website (v1.2, earlier version)

An earlier version of the SIITEC / KMITL faculty website, built with React, styled-components and Framer Motion (scroll-reveal sections, parallax, animated hero).

> **This version has been replaced.** The current site, with English/Thai support, 20+ pages and lazy-loaded routes, is **[Faculty_website](https://github.com/NoeNoe25/Faculty_website)** ([live](https://faculty-website-sigma.vercel.app)).

## Run locally

```bash
cd siitec
npm install
npm start
```
